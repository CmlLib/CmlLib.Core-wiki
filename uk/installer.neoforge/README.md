# Головна

[GitHub](https://github.com/Gml-Launcher/CmlLib.Core.Installer.NeoForge)

Інсталятор NeoForge для [CmlLib.Core](../cmllib.core/README.md).

## Можливості

* Підтримка розробників NeoForge! Після успішного встановлення версії NeoForge у вас автоматично відкриється рекламна сторінка NeoForge.
* Автоматична зміна посилань для встановлення NeoForge
* Автоматичне встановлення ванільної версії Minecraft перед встановленням NeoForge
* Пропуск повторного встановлення NeoForge

## Підтримувані версії NeoForge

Успішно протестовано версії NeoForge **1.20.2 ~ 1.21.10**. [Усі результати тестування](supported-versions.md)

## LLM

Надано файл [llms.txt](https://cmllib.github.io/CmlLib.Core-wiki/en/llms.txt).
